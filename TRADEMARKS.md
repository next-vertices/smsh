# Nom et sources officielles

Le nom **Smsh**, son logo et l'identité du projet appartiennent à **Next Vertices**. Le code source est sous la licence du fichier `LICENSE` ; cette licence ne donne **aucun droit sur le nom ni sur le logo**.

## Sources officielles

Les seules sources officielles de Smsh (code, binaires, paquets, mises à jour) sont :

- le dépôt GitHub : <https://github.com/next-vertices/smsh> (code et *Releases*) ;
- un site web appartenant à Next Vertices.

Tout binaire, paquet ou dépôt provenant d'ailleurs (autre dépôt, forum, *store*, site tiers, message privé) est **non officiel** : n'y faites pas confiance, il pourrait contenir du code malveillant, d'autant que Smsh manipule des clés d'API. Vérifiez les sommes de contrôle `SHA256SUMS.txt` publiées avec chaque release.

## Règles d'usage du nom

- Un fork ou une version modifiée ne peut pas s'appeler « Smsh », ni prétendre être la version officielle, soutenue ou approuvée par Next Vertices.
- Il est permis de dire de façon factuelle qu'un projet est « basé sur Smsh » ou « compatible avec Smsh ».
- Smsh ne peut être ni vendu, ni proposé en échange d'une contrepartie, ni redistribué en dehors des conditions de la licence.

Pour toute demande d'autorisation : ouvrez une issue sur le dépôt officiel.
